# Module · Project workspace (internal)

**Purpose** Run the project on the same data the website shows.
**Users** Sigve, student groups, contractors, advisers.

## Features
- Tasks with owner, due, status; linked to plots, systems or documents
- Decisions log (what, why, who, when) — feeds the news page when public
- Documents with versions and role visibility; folders per topic (regulation, energy, market, site)
- Meetings: agenda, notes, actions
- Stakeholder register with consent and roles
- Milestones timeline (shared with the public project page)

## Data
`document`, `stakeholder`, `event`, `milestone`, tasks table.

## Acceptance
- A student can upload a deliverable, link it to plots, and mark the task done in one flow
- Publishing a milestone to the public page is one toggle
