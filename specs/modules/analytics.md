# Module · Analytics and KPIs

**Purpose** Connect the platform to project outcomes (09).

## Features
- Cookieless traffic analytics (EU-hosted)
- First-party product events (taxonomy in 09) stored in `event`
- Admin KPI dashboard: registrations, conversion, passport shares, investor requests, engagement,
  stakeholder activity; weekly digest email
- UTM capture on leads; source attribution
- Funnel: landing → plot → passport → registration

## Privacy
No personal data in events except a hashed session id; leads separate with consent. Data retention 24 months.

## Acceptance
- KPI numbers reconcile with the `lead` table
- Dashboard loads < 2 s for 12 months of data
