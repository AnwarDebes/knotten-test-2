# Module · UiA research space

**Purpose** Make Knotten a research object: datasets, access, publications.
**Users** UiA students and staff, energy group.

## Release 1
- Dataset registry: LiDAR-derived terrain, trees, plots analysis, road, horizon profiles, model frames —
  with licence (CC BY 4.0 for derived data where sources allow), schema, version
- Downloads for `researcher` role; citation text; contact
- Thesis/publication log

## Release 2+
- API keys with per-key quotas; anonymised meter series (field aggregate, and per-home only with consent)
- Data-sharing agreement template; ethics notes for personal data
- Sandbox notebooks (optional)

## Acceptance
- Every dataset has schema + licence + version; downloads logged
- Personal meter data never leaves without consent flag
